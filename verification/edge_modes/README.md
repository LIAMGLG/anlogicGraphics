## 卡通化

独立模块：user_source/hdl_source/isp/cartoon_96.v。
复用现有 edge_detect_96 的 Sobel 黑白掩码，在轮廓处输出黑色，其余区域使用量化颜色。
每个 R/G/B 通道量化到 0、85、170、255 四档，最多 64 种颜色。
为匹配现有 Sobel 的两像素采样，先对相邻两像素的 RGB 分量取平均，再量化，结果复制到两像素。

Sobel 窗口中心位于输入像素的上一行、前一个像素对；cartoon_96 使用一个 12×320 位颜色行缓存，
缓存量化后的颜色，保证颜色与边缘在空间位置上对应。输出延迟仍为两拍，无需扩展模式寄存器流水线。
卡通画面相对原图向下平移一行、向右平移两个像素。首行、每行首组四像素以黑色填充，
末行及末像素对的原图内容未完整显示。这是当前因果式窗口的边界处理。
颜色与边缘不会错位，但本模块不是完整分辨率的去噪或双边滤波卡通算法。

原有边缘模式参数、输出和延迟保持不变；首两行和每行首组四像素仍遮罩为黑色。
边缘/卡通共用运行时阈值，上电为 60，由 k3 调节。
二值化阈值上电为 64，由 k2 调节。各处理模块持续运行，模式和正常/二值化数据延迟两拍以保持切换对齐。
处理模块沿用原工程实时视频流水线约定，不提供独立的背压缓存。

新模块已加入 td_project/camera_to_dsi_display.al。重新加载工程清单并生成、下载 bit 文件后才能上板使用。

## 仿真

在工程根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File verification/edge_modes/run_sim.ps1
```

可用 -ModelSimBin 指定 ModelSim 可执行文件目录。脚本检查 PASS 标志，不能仅依赖 vsim 退出码。

- tb_edge_modes.sv：Sobel 数值参考、平坦画面、阶跃和纹理、边界、valid 间隔、两种 SOF 时序、复位、真实消抖长按、四模式循环和上电默认正常。
- tb_cartoon.sv：独立数值参考检查 RGB 配对平均、四色阶量化、Sobel 黑轮廓、空间中心对应、连续有效像素、valid 间隔、帧边界和复位。
- tb_isp_modes.sv：以 demosaic/AWB 仿真替身检查四路径选择和两拍控制信号延迟，覆盖相邻帧和连续有效数据；首行卡通输出为边界黑色，第二行验证彩色量化输出。

上述测试通过 ModelSim 10.3c 验证，不模拟完整摄像头、AWB 算术、DDR 或 HDMI 链路。
